# Camper-auto zoeker

Zoekt elk uur hoge personen-MPV's (Berlingo, Partner, Kangoo, Doblò, Combo, Caddy, Nemo, Tourneo Connect)
op Marktplaats en AutoScout24 en toont ze op één pagina (`docs/index.html`, via GitHub Pages).
Instellingen (modellen, maximumprijs) staan in `config.json`. Handmatig draaien: `python3 zoek.py`.
